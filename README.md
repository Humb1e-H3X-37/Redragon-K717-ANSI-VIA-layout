## Installation

1. Download the [VIA layout JSON file](layout-via/k717-ansi-via.json).
2. Open the [VIA web app](https://usevia.app/).
3. If required by your VIA version, open the **Design** tab.
4. Load the downloaded JSON file.
5. Configure your keyboard using the available layers and key mappings.

Menu names and import steps may vary depending on your VIA version.

## Important — Back Up Your Configuration

Before making any changes, download and save a backup of your current keyboard configuration.

If you overwrite your configuration without a backup, you may need to reset your keyboard and configure it again.

**Recommendation:** Keep a Reset button accessible on one of your keyboard layers. It can be very useful if you accidentally change your layout or lose access to your usual key mappings.

## Ergonomics and Mouse-Hand Considerations

I use the keyboard with both hands and operate my mouse with my **left hand**.

If you use your **right hand for the mouse**, consider moving some keys or functions from the right side of the keyboard to the left. This can reduce unnecessary movement and workload on your right hand, making frequently used functions easier to access.

Feel free to adapt the layout to your own preferences and workflow.
