# Redragon K717 – Custom VIA Layout

Custom JSON layout for the Redragon K717 60-key keyboard, intended for use with the VIA keyboard configurator.

## Features

- Custom key labels and layer descriptions
- Documented function-layer mappings
- JSON file ready to import into VIA

## Installation

1. Download the JSON file from this repository.
2. Open VIA.
3. Go to the **Design** tab, if required by your VIA version.
4. Load the JSON file.
5. Configure your keyboard layout.

Menu names and import steps may vary depending on the VIA version.
